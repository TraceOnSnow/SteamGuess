# Archived progressive pool v0.2

These files preserve an early human/AI-generated pool experiment for reference only. They are **not** imported by the current application, do not define runtime difficulty, and must not be treated as a database or publishing input.

Current difficulty authority is `data/catalog/catalog.sqlite`: eligible AI
candidates provide the baseline, accepted player feedback may adjust it, manual
locks have final authority, and `public/games_demo.json` is generated.
